
# DGU B.a.f 9th Activity Projects

**Project Period:** Jun 2021 - Aug 2022

This repository showcases a series of data analysis and machine learning projects undertaken in DGUBAF, the Statistics Club at Dongguk University. This project is a collaborative work with fellow team members of B.a.f. Unauthorized distribution of the contents within this repository is not allowed.   


BAF Website: [https://www.dgubaf.com/](https://www.dgubaf.com/)



## Project Highlights

### 1. Seoul Bike (따릉이) Rental Prediction

* **Period:** Sep 2021 - Nov 2021
* **Description:** Developed a predictive model to forecast the rental demand for Seoul's public bicycle sharing service, Ttareungyi. We utilized a Random Forest Regressor to analyze various factors influencing rental volume.
* **Keywords:** Regression, Random Forest, Time Series, Bike Sharing


### 2. Climate Technology Classification (NLP Study)

* **Period:** Dec 2021 - Feb 2022
* **Description:** The project involved processing natural language data related to climate technologies using the `Konlpy` for Korean text. The processed data was then fed into a neural network to classify climate technology labels.
* **Keywords:** NLP, Konlpy, Text Classification, Climate Tech


### 3. Exercise Action Classification

* **Period:** Mar 2022 - May 2022
* **Description:** Focused on classifying different exercise actions using sensor data. We implemented a 1D Convolutional Neural Network (1D CNN), a suitable architecture for sequential data, to accurately categorize various movement labels.
* **Keywords:** 1D CNN, Deep Learning, Human Activity Recognition, Sensor Data



### 4. Wildfire Risk Analysis

* **Period:** June 2022 - July 2022
* **Description:** Participated in the '2022 Statistical Data Analysis and Utilization Competition' organized by Statistics Korea. This project involved analyzing environmental factors and meteorological information to assess the risk of large-scale wildfires.
* **Keywords:** Environmental Data, Disaster Prediction
